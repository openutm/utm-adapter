# OpenUTM UI fonts

These fonts are bundled locally so branding works without network access.

- `dm-sans.ttf`: DM Sans variable upright font (optical size and weight axes), from
  https://github.com/google/fonts/tree/main/ofl/dmsans.
  License: `DM-Sans-OFL.txt` (SIL Open Font License 1.1).
- `marcellus.ttf`: Marcellus Regular, from
  https://github.com/google/fonts/tree/main/ofl/marcellus.
  License: `Marcellus-OFL.txt` (SIL Open Font License 1.1).

DM Sans is used for interface text and controls; Marcellus is used for page titles.
